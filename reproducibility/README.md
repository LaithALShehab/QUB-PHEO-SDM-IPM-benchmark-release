# Reproducibility Files

This folder contains the minimal code, configuration, and split-protocol notes associated with the final QUB-PHEO SDM--IPM benchmark release.

Included:
- `code/sdm/`: final SDM training/export-related script.
- `code/ipm/`: final hard-chained and soft-state IPM scripts.
- `code/direct_baseline/`: direct fusion baseline dataset/training scripts.
- `configs/`: final configuration file used for the V3.8 SDM--IPM setup.
- `split_definitions/`: participant-held-out split-protocol note.

Excluded:
- raw QUB-PHEO dataset files,
- model weights,
- intermediate development runs,
- review-analysis folders,
- archives and Python cache files.
